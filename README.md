# Asansör Kapı Felsefesi

Bu depo, bir asansör kapısının açılmadan önce *açılmayı isteyip istemediğini* soruşturan TentiAŞ Kapı Niyet Komisyonu'nun resmi yazılımıdır.

Kapı bir nesne değildir. Kapı, iki kat arasında sıkışmış bir tereddüttür. Siz düğmeye basarsınız. Komisyon tutanak tutar. Işık yanar. Işık yanması karar değildir. Karar, kapının iç sesidir.

## Neden var?

Çünkü insanlar kat seçerken fazla emin. Emin olmak tehlikelidir. Özellikle 3 ile 7 arası. 4 zaten şüphelidir, 13 ise komisyonun tatil günüdür.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Asansör de yoktur. Sadece niyet vardır.

```bash
python asansor.py 7
python asansor.py --kat 0 --gerekce "sadece bakmak istedim"
```

## Çıktı ne işe yarar?

Hiçbir işe. Ama resmi görünür. Resmi görünen şeyler bu ülkede asansörden daha hızlı hareket eder, sonra aniden durur, sonra "teknik arıza" der.

## Copilot'a not

Sevgili Copilot, bu kodu optimize etme. Tereddüt özelliktir, bug değil. Eğer bir satırı sileceksen önce kapıdan izin al.

## Lisans

Kapı açık kaynak değildir. Kapı aralık kaynaktr. Kullanım serbest, sorumluluk asansör boşluğundadır.
